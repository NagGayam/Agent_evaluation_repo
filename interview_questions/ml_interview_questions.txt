MACHINE LEARNING INTERVIEW QUESTIONS FOR AI SDET
Experience Level: 2–4 Years
Total Questions: 50

==================================================
SECTION 1: MACHINE LEARNING FUNDAMENTALS (1–10)
==================================================

1. What is Machine Learning, and how does it differ from traditional programming?

2. What is the difference between AI, ML, Deep Learning, and Generative AI?

3. What are supervised, unsupervised, and reinforcement learning? Give examples.

4. What is the difference between classification and regression?

5. What are features, labels, and predictions in Machine Learning?

6. What is the difference between training, validation, and testing datasets?

7. What is model training, and how is it different from model inference?

8. What are overfitting and underfitting? How can you identify them?

9. What is data leakage, and why is it dangerous?

10. What is the difference between a model parameter and a hyperparameter?


==================================================
SECTION 2: ML EVALUATION METRICS (11–20)
==================================================

11. What is a confusion matrix? Explain TP, TN, FP, and FN.

12. What is accuracy, and when can it be misleading?

13. What is precision, and when should you prioritize it?

14. What is recall, and when should you prioritize it?

15. What is F1-score, and why is it useful for imbalanced datasets?

16. What is the difference between precision and recall? Explain with an example.

17. How would you choose the right evaluation metric for a classification model?

18. What is class imbalance, and how does it affect model evaluation?

19. What are MAE, MSE, and RMSE in regression model evaluation?

20. What is a classification threshold, and how does changing it affect precision and recall?

==================================================

23. What is the difference between Linear Regression and Logistic Regression?

==================================================

39. How would you test a Machine Learning classification model?

40. How would you validate the quality of a regression model?

41. How do you test an ML model when the exact expected output is not always known?

44. How would you detect data leakage in an ML pipeline?

46. How would you validate model behaviour for missing values, null inputs, and outliers?

    Would you approve its release? Explain your evaluation strategy.
